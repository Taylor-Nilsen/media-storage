# media-storage

Public media for https://media.taylornilsen.com, served free by GitHub Pages.

A file at `cad/rear-wing.png` in this repo is live at `https://media.taylornilsen.com/cad/rear-wing.png` about a minute after it lands on `main`.

## Upload

GitHub repo page → Add file → Upload files → drag files in → Commit to `main`.

Only you can push to `main`, so nobody else can upload or change files.

## Limits (free, none of them bill)

- 25 MB per file through the web uploader, 100 MB per file through `git push`.
- 1 GB total site size, ~100 GB/month bandwidth (soft limit, GitHub emails you, never charges).
- Do not turn on Git LFS. Pages can't serve LFS files and LFS has paid storage.
